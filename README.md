# Open source handlebar endcap
Open source 3D printable endcap for bicycle handlebars.

Designed for personal use and remixing — see license details below for commercial terms.

## 🧩 What's Included

- 3D models designed in Freecad
- stl files
- This README and LICENSE.txt

### stl file naming format
The naming format of the stl files indicates the inner (ID) and outer (OD) diameter of the handlebar tube and the handlebar tape thickness (TT).

So the format is `ID_OD_TT.stl` for stl files without the designed support and `ID_OD_TT_DS.stl` where "DS" is not a number but stands for "designed support", those files include the designed support which means you can print the endcap at a 45°angle without generating supports in a slicer and that makes a stronger part than if you print it flat on the bed.

The units are in **mm**.
